## Versioning rules

- Never edit a canonical doc in place without bumping the version in the filename and the header.
- Decision Log entries are append-only. A reversal is a new entry marking the old one SUPERSEDED.
- When a new version is released, upload the same file to both Projects and remove the obsolete copy. Neither platform syncs with the other on its own.
- Protocol v1.2 and KB v1.1 corrections are queued in Decision Log Part F.
